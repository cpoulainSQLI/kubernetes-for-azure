About the courses

Goal

Take someone who has never used containers to the point where they can run applications on Kubernetes, then on the platforms built on it: GitOps with Argo CD, Azure Kubernetes Service (AKS), OpenShift and Azure Red Hat OpenShift (ARO).

Every course is hands-on. You work in your own environment and check your own work with a validation script. The catalogue lists the courses.

How the courses fit together

  • Each course can be followed alone. A later course expects the knowledge of an earlier one, never its labs or its environment.
  • Each course has its own lab kit and its own course command, so the commands of one course never touch another.
  • The courses that need no cloud run on your own computer. Only the courses on AKS and ARO use Azure, and what they need from it (a subscription, a budget, quotas, regions) is written once for all of them.
  • The courses do not teach Azure itself. Where an Azure basic is needed, they link to Microsoft Learn.

Out of scope

  • Azure fundamentals, which Microsoft Learn covers.
  • Writing application code. The sample app is provided.
  • Installing self-managed OpenShift (installer-provisioned or user-provisioned infrastructure).
  • OpenShift Virtualization and OpenShift AI.
  • Preparing for a certification exam.
  • Production hardening beyond what each chapter states. The labs are built for learning, not as production templates.
