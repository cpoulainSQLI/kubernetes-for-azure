Containers and Kubernetes

Build an image for a small web app, run it, push it to a registry, then run it on a Kubernetes cluster. Every lab runs on your own computer, and a script checks your work task by task.

This is course 1 of Kubernetes, hands-on. You need no cloud account and pay nothing. On Windows the labs run in a Linux distribution of WSL 2 that the course creates for you, and on Linux they run on your machine. Start with the Introduction, then the Setup.

The course is being rebuilt for your own computer. The Setup page describes the new environment. Chapters 1 and 2 still describe the former Azure lab VM, and their labs already run in the new environment.

Before you start

You can type commands in a terminal and edit text files. You do not need to know containers or Kubernetes, and you do not write application code: the course gives you a small web app in Go.
