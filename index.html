Kubernetes, hands-on

Short courses on containers, Kubernetes and the platforms built on it. In each one you run labs on your own environment, and a script checks your work task by task and tells you what to fix.

Each course stands on its own. A later course expects you to know what an earlier one teaches, but not to have its labs or its environment. Each course says what you should be able to do before you start.

The first courses run on your own computer, with no cloud account and no bill. Only the courses on Azure Kubernetes Service and Azure Red Hat OpenShift use Azure, and they will say what each lab costs before you run it.
