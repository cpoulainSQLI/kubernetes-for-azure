# Archive

Draft material from an earlier version of the course, kept unchanged. It will be reworked for chapter 7 (OpenShift).

- `lessons/0001-where-openshift-and-aro-sit.html` is a lesson on where Kubernetes, OpenShift and ARO sit in relation to each other.
- `reference/kubernetes-openshift-aro-layers.html` is a one-page reference sheet of the same layers.
- `assets/course.css` and `assets/quiz.js` are the style sheet and the quiz script that both pages load.
- `tools/inline.py` builds a self-contained copy of a page, with the style sheet and the script inlined.

These files do not follow the current [style guide](../STYLE.md) yet and are excluded from the course checks, except the personal data check.
