The family

NameWhat it is
KubernetesThe upstream orchestrator. Red Hat calls it the "kernel" of the stack. [1]
OKDCommunity distribution of Kubernetes, formerly Origin, upstream of OpenShift. [1]
OpenShift Container PlatformRed Hat's supported product, OKD plus operators and other components. [1]
AROOpenShift on Azure, jointly engineered, operated and supported by Microsoft and Red Hat, clusters in your subscription, 99.95% SLA. Standard or hosted control planes (preview). [4]
AKSMicrosoft's own managed Kubernetes, listed separately from ARO. No OpenShift layer. [5]

oc and kubectl

OpenShift is a certified Kubernetes distribution, so kubectl works. oc does the same and adds OpenShift features. [3]

CommandWhat it does
oc login --token=... --server=...Authenticates and writes the kubeconfig that kubectl also uses
oc whoamiShows the user you are logged in as
oc projectShows the current project (an OpenShift wrapper around a namespace)
oc new-project <name>Creates a project and switches to it [3]
oc new-appStarts an app from source code or an image [3]
oc api-resources --api-group=route.openshift.ioLists the Route resource. kubectl shows the same, the objects live in the API server
