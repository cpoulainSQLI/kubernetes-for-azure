# Kubernetes and Azure Red Hat OpenShift, hands-on

A hands-on course, from zero containers to an Azure Red Hat OpenShift cluster, with labs on your own Azure subscription.

The course is a static HTML site. Open [index.html](index.html) in a browser to start, or read the published site, which GitHub Pages serves from the `main` branch. The empty `.nojekyll` file tells GitHub Pages to publish the files as they are.

The labs need the folder itself on your computer, because the scripts run from it. Download it as a zip file or clone it.

Contributors read [style-guide.html](style-guide.html). It lists the checks to run before a change.
