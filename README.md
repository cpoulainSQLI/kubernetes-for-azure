# Kubernetes and Azure Red Hat OpenShift, hands-on

A hands-on course, from zero containers to an Azure Red Hat OpenShift cluster, with labs on your own Azure subscription.

The course is a static HTML site. Open [index.html](index.html) in a browser to start, or read the published site: the workflow in `.github/workflows/pages.yml` publishes this folder with GitHub Pages on every push to `main`.

The labs need the folder itself on your computer, because the scripts run from it. Download it as a zip file or clone it.

Contributors read [style-guide.html](style-guide.html). It lists the checks to run before a change, which `.github/workflows/checks.yml` also runs on every push.
